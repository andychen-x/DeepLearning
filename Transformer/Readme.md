# Transformer Model


![Transformer](https://github.com/andychen-x/DeepLearning/blob/main/Transformer/Transformer.png)


## 1. 输入层
Transformer 的输入层负责将离散的序列数据转换为模型可处理的向量表示，由词嵌入（Embedding）和位置编码（Positional Encoding）两部分组成。首先通过输入 / 输出嵌入层，将源序列、右移一位的目标序列中的每个 token 映射为固定维度的稠密语义向量；再叠加位置编码，为向量注入序列的位置顺序信息，弥补注意力机制无法天然感知时序的缺陷，最终将融合后的向量送入编码器与解码器。


## 2. 编码器
Transformer的编码器由6个相同的层组成，每个层包括两个子层:一个多头自注意力层和一个逐位置的前馈神经网络。在每个子层之后，都会使用残差连接和层归一化操作，这些操作统称为Add&Norm。这样的结构帮助编码器捕获输入序列中所有位置的依赖关系。


## 3. 解码器
Transformer的解码器由6个相同的层组成，每层包含三个子层:掩蔽自注意力层、Encoder-Decoder注意力层和逐位置的前馈神经网络。每个子层后都有残差连接和层归一化操作，简称Add&Norm。这样的结构确保解码器在生成序列时，能够考虑到之前的输出，并避免未来信息的影响。


## 4. 输入层
Transformer 的输出层负责将解码器的特征表示转换为最终的预测结果，由线性层（Linear）和Softmax 激活层组成。首先通过线性层，将解码器输出的特征向量映射到与词表大小一致的维度，得到每个 token 的原始得分；再通过 Softmax 层将得分转换为合法的概率分布，概率最高的 token 即为模型当前位置的预测输出，最终完成序列到序列的生成任务。
